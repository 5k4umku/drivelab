# Погрешность шага и приработка

Режим `gost.runningInMode = "table10"` использует погрешности основного шага каждого венца, его предел контактной выносливости и окружную скорость. Для материала с однородной структурой yα = 160 fpb / σHlim. При v < 5 м/с верхнего ограничения нет, от 5 до 10 м/с включительно предел равен 12800 / σHlim, выше 10 м/с — 6400 / σHlim. Для поверхностного упрочнения yα = 0,075 fpb с пределом 3 мкм. Сначала ограничивают вклад каждого венца, затем усредняют два результата. [ГОСТ 21354–87, табл. 10](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=24)

Погрешности `fpb1` и `fpb2` относятся к отдельным колёсам. Если при расчёте резонанса задана погрешность пары `gost.dynamics.pitchError`, приработка для приложения 5 пересчитывается с этой величиной. Расчёт записывает оба значения приработки и использует их при повторной проверке максимальной нагрузки. Для распределения изгибной нагрузки между зубьями yα принимается равным нулю. [Табл. 6, п. 8](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=19) · [Табл. 13, п. 5](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=32)

Степень точности и модуль задают g₀ по таблице 9. Для статистического коэффициента aα стандарт указывает нижнюю границу. Чтобы использовать статистику производства, введите эффективную погрешность пары до приработки в `gost.pitchStatisticH` для контакта и в `gost.pitchStatisticF` для изгиба. Поле `gost.alphaEvidence` содержит источник данных и критерий выбора этой величины. По члену aα·fpbe расчёт находит отношение эффективной погрешности к fpbe = √(fpb₁² + fpb₂²). При необходимости поднимает коэффициент до границы соответствующей проверки. Для контакта это 0,2 при наличии хотя бы одного венца с HV ≤ 350 и 0,3 для двух более твёрдых венцов. Для изгиба нижняя граница равна 0,4. [Табл. 6, п. 8 и таблица 9](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=20)

Для прежних проектов исходные допущения сохраняются. В ручном режиме можно задать `gost.yAlpha`, `gost.aAlpha` и `gost.aAlphaF`. Назначенный коэффициент aα ниже единицы без указанного источника требует подтверждения. Признак модификации головок прямых зубьев `gost.tipRelief` участвует в выборе δH и δF. [Табл. 8](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=23)
