# Конструктор цилиндрического редуктора

Конструктор собирает последовательную цепочку зубчатых ступеней на параллельных валах. Число ступеней и положение опор не привязаны к номеру семинарского задания. Шаблон №11 сохраняет исходный одноступенчатый вариант; остальные шаблоны задают только начальную компоновку.

## Работа с моделью

1. Задайте мощность и частоту на входе. Добавляйте, удаляйте и переставляйте ступени.
2. Для каждой ступени выберите прямые, косые или шевронные зубья, передаточное число, КПД, ширину и межосевое расстояние. Ноль в поле межосевого расстояния означает подбор. Через «Расчёт ступени» доступны материалы, ресурс, модули и все исходные коэффициенты.
3. Угол в плоскости XY задаёт направление от оси шестерни к оси колеса. Осевая координата Z задаёт положение венца вдоль вала. Пустое поле Z автоматически размещает соседние венцы с зазором 20 мм по торцам.
4. На каждом валу выберите расположение венцов между опорами, смещённое или консольное. Для произвольных координат включите ручной режим. Опора B должна находиться правее A. Диаметр вала задаётся для компоновки.
5. Проверьте реакции, эпюры изгибающих моментов и пересечения габаритов. Затем перейдите к подробному расчёту каждой ступени.

Переключение типа зубьев, геометрии или опор сбрасывает подтверждение применимости коэффициентов распределения нагрузки. KHβ и KFβ остаются явными исходными данными. Статические реакции не определяют их однозначно: нужны жёсткость валов, опор и корпуса, погрешности и условия приработки.

## Расчётная цепочка

Мощность следующей ступени равна `P(i+1) = P(i) η(i)`, частота — `n(i+1) = n(i) / uф(i)`. Используется фактическое отношение чисел зубьев. Общее передаточное число и КПД — произведения по ступеням. Проверяется также суммарная ошибка передаточного числа: малые отклонения отдельных ступеней могут накопиться.

Промежуточный вал общий для колеса предыдущей и шестерни следующей ступени. Знак скорости меняется на каждом внешнем зацеплении. Мощность и частота промежуточного вала вычисляются из предыдущей ступени, поэтому в подробной форме они доступны только для чтения.

## Статика опор

Все координаты — в мм, силы — в Н, вывод изгибающих моментов — в Н·м. Ось Z направлена вдоль валов, оси X и Y задают плоскость компоновки. Номинальные силы зацепления приложены в полюсе, а не в центре колеса. Это сохраняет изгибающий момент от осевой силы на делительном радиусе.

Для опор A и B с пролётом L:

```text
ΣFx = ΣFy = ΣFz = 0
ΣMx = ΣMy = 0
M = r × F
RBx = −ΣMy,A / L
RBy =  ΣMx,A / L
RAx = −ΣFx − RBx
RAy = −ΣFy − RBy
```

Одна выбранная опора воспринимает всю осевую реакцию; другая считается плавающей. Суммарный изгибающий момент вычисляется с обеих сторон каждой сосредоточенной нагрузки и опоры. Между ними компоненты момента линейны, поэтому достаточно концов участков. В журнале проверяются остатки равновесия по силам и двум изгибающим моментам. Момент вокруг Z передаётся через привод; он не включён в проверку радиальных опор.

Это применение уравнений статики, а не отдельная формула ГОСТ 21354–87. Основание: [OpenStax, University Physics, §12.1](https://openstax.org/books/university-physics-volume-1/pages/12-1-conditions-for-static-equilibrium). Расчёт прочности зубьев остаётся в рамках [реализованного профиля ГОСТ](gost-coverage.md).

## Геометрические проверки

Проверяются диаметр вала относительно впадин зубьев, положение условных опор вне венцов, пересечения несопряжённых венцов, валов с венцами и валов между собой. Венцы оцениваются по цилиндрическим габаритам вершин зубьев; предусмотренное зацепление пары исключено из проверки пересечений. Это предварительный контроль компоновки, а не точная проверка столкновений производственных поверхностей. Кольца опор и габаритный контур в 3D условны.

## Формат проекта и ограничения

JSON версии 2 содержит весь редуктор: общие входы, массив ступеней и массив валов. Старый JSON версии 1 преобразуется в одноступенчатую модель. Автосохранение также переносится автоматически. Отчёт по редуктору включает кинематику цепочки, реакции, значения эпюр, проверки компоновки и полный журнал каждой ступени. Отдельный отчёт выбранной ступени сохранён.

Технический предел массива — 64 ступени, чтобы ограничить размер импорта и потребление памяти. Это не утверждение, что любая цепочка из 64 ступеней физически работоспособна: диапазоны размеров, скоростей и методов проверяются для каждой ступени.

Модель предполагает внешний зубчатый контакт, нулевые смещения профиля и два радиальных подшипника на вал. Внутреннее зацепление, замкнутые и разветвлённые кинематические цепи, несколько потоков мощности и статически неопределимые многоопорные валы не реализованы. Не рассчитаны ресурс подшипников, усталость и прогибы валов, шпонки, корпус, смазочная система и тепловой баланс. В статику не включены вес деталей, пусковые и внешние нагрузки на концы валов. Эти ограничения отображаются в приложении и отчёте.
