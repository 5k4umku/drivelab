# Косозубая пара из приложения 11

[Открыть файл для импорта в DriveLab](../examples/gost-annex-11.json). В таблицах 37–40 приведён пример расчёта выносливости одноступенчатой передачи. Таблица 40 заканчивается на печатной странице 124. Таблицы 41 и отдельного контрольного результата для максимальной нагрузки в этом приложении нет. [ГОСТ 21354–87, приложение 11](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=110)

## Исходные условия

Шестерня из стали 25ХГМ имеет 32 зуба и нитроцементированную поверхность. Колесо из 40Х имеет 64 зуба и закалено ТВЧ по контуру впадины. Нормальный модуль 5 мм, угол наклона 16°15′, ширина обоих венцов 60 мм, смещения равны нулю. Входной момент 1970 Н·м, частота вращения 1500 об/мин, ресурс 1000 ч. В файле указана мощность, соответствующая этому моменту по принятой в приложении зависимости DriveLab T = 9550 P / n.

Для непосредственного сопоставления приняты опубликованные KHβ = 1,14 и KFβ = 1,12, обе погрешности шага 19 мкм, yα = 2,1 мкм. Твёрдость и YR заданы по каждому венцу отдельно. Доли углерода и азота в паспорте шестерни выбраны внутри диапазона строки 1 таблицы 15. Приближённый перевод твёрдости сердцевины в HRCэ, 650 HV поверхности шестерни и эти концентрации являются входными допущениями примера. Толщина слоя в таблице 37 дана интервалом 0,8–1,1 мм. Расчёт глубинной прочности в приложении 11 отсутствует.

## Откуда берутся расхождения

1. Таблица 37 задаёт 1970 Н·м. Подстановка этого момента и d₁ = 166,7 мм в 2000 T / d₁ даёт около 23,64 кН. В таблицах 39 и 40 напечатано 25,635 кН. Программа использует момент из исходных условий во всех последующих формулах.
2. Таблица 37 задаёт 58 HRCэ для шестерни. В строке 27 таблицы 39 подставлено 59 HRCэ. По таблице 12 получаются соответственно 1334 и 1357 МПа (в примере округлено до 1360 МПа). Для колеса обе подстановки дают 1050 МПа.
3. При сборке допуска пары в строке 37 таблицы 39 использована полусумма. На печатной странице 19 предписан коэффициент 0,45 с нижней и верхней границами. При вычисленных по отдельности допусках 1165,49 и 957,66 МПа выражение с 0,45 оказывается ниже меньшего допуска. Применяется нижняя граница 957,66 МПа.
4. Для изгиба таблица 40 принимает KFα = KHα = 1,02. В DriveLab уточнённый KFα рассчитывается при yα = 0 и aα = 0,4 по пункту 5 таблицы 13, что даёт 1,1490. Для контакта использованы yα = 2,1 мкм и aα = 0,3. У разных видов проверки остаются свои коэффициенты.
5. По пункту 12 таблицы 13 при m = 5 мм Yδ = 1,082 − 0,172 lg(5) = 0,9618. В строке 24 таблицы 40 приведена другая зависимость и в итоговую подстановку взято 1,00. Для YR в этом файле явно сохранены значения самого примера, 0,95 и 1,05.

Проверить пример из корня репозитория можно командой `python -m unittest discover -s tests -p test_gost_example.py`. Тест читает тот же JSON, который открывает браузер, сверяет совпадающие параметры с точностью печатной таблицы и отдельно проверяет расчётные расхождения.
