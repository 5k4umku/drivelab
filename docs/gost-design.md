# Предварительные размеры по приложению 1

Раздел 5 даёт две оценки по контактной выносливости — начальный диаметр шестерни и межосевое расстояние. По изгибу шестерни рассчитываются два значения модуля. Первое относится к назначенной относительной ширине ψbd. Второе показывает, какой модуль нужен при известных рабочей ширине и межосевом расстоянии. В итоговой ведомости эти размеры приводятся до округления до стандартного ряда. Окончательный вариант проверяют по разделам 3 и 4. [Пункты 5.1–5.2, с. 57–60](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=58)

В расчёт входит момент на колесе в Н·м. Для циклограммы перебираются стороны зацепления и их эквивалентные моменты из приложения 3. Контактную и изгибную оценки может определять разная сторона. При реверсе проектировочное допускаемое напряжение изгиба уменьшается на 25%. Для косого зуба и шеврона верхняя граница контактного допуска в п. 5.1.6 составляет 1,23 меньшего из двух значений σHP.

## Исходные данные

В объекте `gost.design` можно задать параметры проектирования.

| Поле | Смысл |
|---|---|
| `psiBd` или `psiBa` | Отношение рабочей ширины к начальному диаметру шестерни или к межосевому расстоянию |
| `centerDistance`, `width` | Межосевое расстояние и ширина зацепления в мм для второго способа определения модуля. По умолчанию используются размеры выбранной пары |
| `scheme` | Номер 1–7 у схемы опор на черт. 13а/б стандарта. Номер относится к рисунку ГОСТ |
| `hardPair` | Если паспортов с HV нет, признак того, что оба венца твёрже 350 HV. В качестве исходного значения также используется заданная HV менее твёрдого венца |
| `KHbeta`, `KFbeta` | Коэффициенты, когда конструктор считал их с графика самостоятельно. При отсутствии номера схемы расчёт использует значения из проекта |
| `YFS1` | Коэффициент формы зуба шестерни, снятый с черт. 10. По умолчанию используется приближение табл. 13, п. 6 для выбранного инструмента |
| `reversing` | Уточняет наличие реверса при ручном вводе YA. Для заданной циклограммы направление определяется её знаками |

Графики 13а/б оцифрованы по скану с округлением значений коэффициентов до сотых. Между соседними точками используется линейная интерполяция. Если ψbd лежит правее конца линии выбранной схемы, результат содержит диапазон, в котором возможно чтение. При сравнении близких вариантов стоит сверить коэффициент с линией на рисунке. [Чертежи 13а и 13б, с. 58–59](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=59)

## Контрольный пример

Для прямозубой пары с u = 2, z₁ = 20, T₂H = T₂F = 40 Н·м, ψbd = 0,8, KHβ = 1,2, KFβ = 1,3 и YFS1 = 4 примем проектировочные σHP = 450 МПа и σFP1 = 200 МПа. Подстановка в п. 5.1.2 даёт dw₁ = 46,64 мм и aw = 71,39 мм. По относительной ширине m = 1,646 мм. Если межосевое уже назначено 75 мм, а рабочая ширина 25 мм, вторая формула п. 5.2.3 даёт m = 0,896 мм. Разные исходные ограничения приводят к разным оценкам. Область применения стандарта для назначаемого модуля начинается с 1 мм.
