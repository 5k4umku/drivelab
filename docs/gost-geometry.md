# Геометрия и смещение профиля

Для внешней пары с исходным углом 20° приложение 2 связывает нормальный модуль, числа зубьев, угол наклона и смещения с рабочим межосевым расстоянием. Если сумма смещений равна нулю, рабочий угол αtw совпадает с делительным αt. Даже в этом случае индивидуальные смещения меняют диаметры вершин, участки линии контакта и коэффициенты изгиба. [ГОСТ 21354–87, приложение 2, таблица 20](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=61)

В расчёте `aW` — рабочее межосевое расстояние, `d1` и `d2` — делительные диаметры, `dw1` и `dw2` — начальные. В знаменатель формулы окружной скорости входит делительный диаметр шестерни. Для прямого зуба осевое перекрытие равно нулю. Для шеврона формула осевого перекрытия использует рабочую ширину одного полушеврона.

Диаметры вершин вычисляются по п. 5 таблицы 20. При пересечении профилей до окружности вершин или выходе контакта за основную окружность приложение отклоняет пару. Для укороченной головки или специальной переходной кривой нужна геометрия фактически изготовленного зуба.

Удельная жёсткость пары учитывает оба смещения. Для изгиба можно независимо выбрать способ нарезания каждого колеса. Формула для инструмента с протуберанцем относится к геометрии инструмента с hₐ₀/m = 1,4 и Pᵣ₀/m = 0,05. Обе приближённые формулы YFS предполагают отсутствие шлифовочной ступеньки.
