# Переменный режим нагрузки

Методы приложения 3 работают с циклограммой одного венца и одной рабочей стороны зуба. Для каждого интервала требуются число циклов за ресурс и действующий момент или напряжение. Нагружение противоположной стороны рассчитывается отдельно, если при реверсе меняются условия работы. Редкие перегрузки сохраняются для самостоятельной проверки. [Область проверок и реверс](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=14)

## Метод 1. Эквивалентные циклы

`gost_duty.equivalent_cycles` выбирает контактный момент TH по наибольшей нагрузке, действующей не менее 0,03 NHlim циклов. Для изгиба TF выбирается по наибольшей нагрузке с числом циклов более 50 000. Если исходная нагрузка определяется на другом элементе передачи, `reference_index` задаёт соответствующую ступень. Числа циклов рассчитываемого венца поступают в `cycles`. Для шестерни и колеса они обычно различаются.

Контактная сумма зависит от отношения моментов в степени 3. При переменной скорости в неё входят νH и отношение ZvH/Zvi в степени 6. Коэффициент μ получается суммированием по ступеням с последовательной проверкой двух условий остановки. Статусы `all`, `cutoff` и `partial` различают полный перебор, остановку до следующей ступени и ограничение текущей частичной суммы. Возвращаемое эквивалентное число циклов равно μNlim. Моменты выше TH или TF перечислены в `overloads` для отдельной проверки.

Для изгиба на стр. 65 в числителе формулы μFk напечатано (Ti + νF TF)n₁, а в знаменателе TH(1 + νF)nH. Для TH и nH используются данные контактной опорной ступени в `contact_reference`. В качестве n₁ используется частота первой ступени циклограммы по убыванию момента. При разных скоростях или разных опорных моментах функция добавляет замечание для сверки с методом 3. [Приложение 3, пп. 1.1 и 1.2](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=63)

## Метод 3. Эквивалентные напряжения

`gost_duty.equivalent_stress` получает напряжения, рассчитанные для каждой фактической ступени. Интервалы одного уровня напряжений объединяются перед проверкой длительности. Для контакта учитываются ступени с Nci > 0,03 NHlim и σHi ≥ αHG σHlim, для изгиба — с σFi ≥ αFG σFlim. Рекомендуемые пороги равны 0,75 и 0,6 соответственно. Возвращённые индексы показывают, какие строки исходной циклограммы вошли в сумму.

Для контакта выше предела усталости используется шестая степень, ниже — двадцатая. В смешанном режиме вклад нижней ветви в среднее шестой степени равен σHi²⁰/σHlim¹⁴. Для изгиба используется qF соответствующего венца. Во всех случаях веса определяются по сумме циклов принятых ступеней. Если отбор не прошла ни одна ступень, эквивалентное напряжение остаётся неопределённым. [Приложение 3, пп. 3.1 и 3.2](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=67)
