# Расширение для курсового

Текущая версия закрывает расчёт выбранной ступени с явно ограниченным профилем ГОСТ. Следующие этапы должны иметь собственные эталоны и проверку применимости.

1. **Валы и опоры.** Реакции, эпюры изгиба и кручения, жёсткость, подшипники, уточнение распределения нагрузки по ширине венца.
2. **Многоступенчатый привод.** Распределение общего передаточного числа, мощности и ресурс по ступеням, каталог двигателей.
3. **Технология.** Заготовки, припуски, реальные режимы термообработки, шероховатость, смазка, корпус и тепловой баланс.
4. **Расширение ГОСТ.** Смещения профиля, поверхностное упрочнение, заданные спектры нагрузки, реверс, резонансная область — по отдельным проверенным ветвям.
5. **Документация.** Параметрические чертежи, экспорт STEP/DXF и составление расчётно-пояснительной записки всего привода.

Зубчатая 3D-модель сейчас иллюстрирует расчётную геометрию. Переходная кривая и технологические элементы должны быть уточнены перед производственным CAD-экспортом.
