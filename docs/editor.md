# Редактор схемы, двигатель и внутренняя пара

## Компоновка мышью

В конструкторе есть два вида одной модели.

- **Развёртка вдоль валов:** каждый вал показан отдельной строкой, шкала Z общая. Перетаскивайте зелёный венец или опору A/B. Венцы одной пары перемещаются совместно, чтобы сохранить плоскость зацепления. Для разных условий опирания двигайте опоры каждого вала независимо.
- **Вид с торца:** перемещайте номер выходного вала ступени по окружности. Меняется направление между осями, а расчётное межосевое расстояние сохраняется. Следующие ступени перестраиваются вместе с цепочкой.

Выбранную координату можно ввести числом под схемой. Стрелки клавиатуры меняют её на 1 мм или 1°, Shift — на 10. Есть отмена и повтор последних перемещений. Изменение проекта вне схемы сбрасывает эту историю, чтобы отмена не восстанавливала чужие настройки.

При первом ручном перемещении текущие положения остальных венцов и опор фиксируются: переход из автоматической компоновки не сдвигает соседние детали. После отпускания мыши Python заново рассчитывает геометрию, реакции, эпюры, пересечения и Т5. 2D и 3D строятся из этого результата. Схему можно сохранить в SVG; координаты, типы опор и двигателя входят в JSON проекта.

У каждого вала две радиальные опоры и одна фиксирующая осевая. Шариковая и роликовая опоры обозначены по-разному; золотым выделена фиксирующая. Это условная схема, без выбора номера подшипника. Корпус — габаритный эскиз с заданным зазором, а не готовая литая деталь. Развёртка сохраняет продольный масштаб; расстояние между её строками не соответствует межосевым расстояниям.

## Двигатель

Встроены паспортные точки Omec Motors при 50 Гц, S1: АИР80B4 (1,5 кВт, 1400 мин⁻¹), АИР90L4 (2,2 кВт, 1410 мин⁻¹), АИР100L4 (4 кВт, 1435 мин⁻¹). Ссылки на конкретные карточки изготовителя записаны в [каталоге](../src/motors.json) и доступны в интерфейсе. Можно задать собственный двигатель с источником характеристик.

Выбор переносит номинальные мощность и частоту на вход. Рабочую мощность затем можно уменьшить. Модель предполагает прямое соединение: несоответствие частоты и превышение номинальной мощности отмечаются в проверках.

`Tном = 9550 Pном / nном`, `Tпуск = Kп Tном`. Коэффициент пуска относительно рабочей нагрузки — `Tпуск / Tраб`. Например, АИР90L4 при половинной нагрузке имеет коэффициент 4,6 относительно рабочего момента, хотя паспортная кратность относительно номинального равна 2,3. КПД двигателя не вычитается из механической мощности повторно. Реакции опор и эпюры показаны для номинальных рабочих сил; динамика разгона не моделируется.

Габариты двигателя в 3D условные. Присоединительные размеры, тепловой режим и работа с преобразователем частоты требуют данных изготовителя.

## Внутреннее зацепление

Выберите его в карточке ступени и задайте модуль, числа зубьев, ширину, угол наклона и толщину обода. Поддерживаются прямые, косые и шевронные зубья. У косозубой внутренней пары направления винтовой линии одинаковые; вращение шестерни и колеса — в одну сторону.

Номинальная геометрия рассчитана по [ГОСТ 19274–73](https://files.stroyinf.ru/Data/173/17345.pdf), таблица 2, для `x₁=x₂=0`, `ha*=1`, `c*=0,25`:

- `d = mn z / cos β`, `aw = (d₂−d₁)/2`;
- `da₁ = d₁+2mn`, **`da₂ = d₂−1,6mn`**;
- `df₁ = d₁−2,5mn`, `df₂ = d₂+2,5mn`.

Предварительное торцовое перекрытие использует выражение таблицы 7, п.15, без ограничения активного профиля переходными поверхностями. Полная проверка интерференции, срезания и условий сборки по таблицам 7–8 требует параметров долбяка и здесь не выполнена. Поэтому внутренняя пара всегда сохраняет статус «требует уточнения» даже при выполненных числовых условиях.

ГОСТ 21354–87 относится к внешнему зацеплению. Его прочностные коэффициенты и напряжения внутренней паре не приписываются. В журнал внутренней пары входят только заданная геометрия, кинематика и номинальные силы. 3D показывает зубчатый обод с отверстием; диск, ступица, крепление и способ сборки требуют конструирования. Корневые переходы схематичны.

Пример [редуктора с АИР90L4](../examples/reducer-editor.json) сочетает внешнюю и внутреннюю ступени. Его можно загрузить кнопкой «Открыть».
