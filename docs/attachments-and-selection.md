# Как использованы вложения

## Zubil

В переданном `Zubil.html` указан автор Павел Зарубов. Алгоритм изучен по
исходному JavaScript, затем независимо перенесён на Python в `selection.py`:

1. Для каждой целой суммы zΣ взять floor и ceil от zΣ/(u+1).
2. Вычислить uф, относительное отклонение, НОД и НОК.
3. В заданном допуске предпочесть максимальный НОК.
4. Если решения в допуске нет, показать ближайшее с явным предупреждением.

В DriveLab при равном НОК дополнительно сравнивается погрешность; при равной
погрешности — сумма зубьев. Ограничение u≥1 исключает неоднозначность исходного
алгоритма, который сравнивал больший венец с меньшим и при u<1 давал другой смысл
отношения. НОК вычисляется целочисленно; число оборотов до повторной встречи
той же пары зубьев равно НОК/z₁. Большой НОК сам по себе не доказывает ресурс.

В отдельном калькуляторе Zubil это кинематический подбор. В проектировочном
расчёте диапазон сумм определяется модулем, межосевым расстоянием и углом
по бланку семинара; далее выполняются проверки геометрии и прочности.
Сохранился прежний режим минимальной ошибки с взаимно простыми числами.

## Архив ПДМ

Из архива СтудИзбы прочитаны инструкция PDF, схемы `PDM.SXM`, таблицы
`ISZC89.DAT` и `ISZPROE.DAT`. DOS-программы не выполнялись, двоичный код
расчётов не выдаётся за проверенный алгоритм.

Из схем взяты идеи отдельных шаблонов прямозубой, косозубой и шевронной
одноступенчатой передачи с венцами между опорами. Они построены средствами
DriveLab; геометрия и реакции пересчитываются по текущей модели.
Сами EXE, изображения и архив не публикуются в репозитории.

Сопоставление типовых режимов из DAT с ГОСТ 21354–87, табл.35:

| Величина | ПДМ | ГОСТ, используемый в DriveLab |
|---|---|---|
| μH, режимы 0–V | 1; .5; .25; .18; .125; .063 | Совпадают |
| μF, q=6, режим II | .14 | .143 |
| μF, q=6, режим III | .06 | .065 |
| μF, q=9, режим III | .04 | В использованном скане .063; профиль У работает с q=6 |

Таким образом, старые таблицы служат материалом для сравнения, но не заменяют
источник нормы. Инструкция ПДМ описывает сохранение `.res` и открытие в Word;
DriveLab сразу формирует редактируемый `.docx` без ручной настройки кодировки.

## Автоматизация и погрешности

Поиск перебирает 3 последовательных размера R10, до 2 значений ψbd и точности
6–9. Каждая проба пересчитывает весь редуктор, включая фактические частоты,
Т5 по опорам, реакции и проверки компоновки. Результат условный: подтверждение
технологических условий не ставится автоматически. При отсутствии численно
пригодных решений список не превращается в рекомендацию.

Чувствительность — расчёт одной и той же геометрии при трёх рабочих моментах.
Параметры материала и частота фиксированы. Это не доверительный интервал:
вероятностная модель входных данных и измерительный эксперимент не заданы.

Квалитеты IT5–IT12 для размеров до 500 мм взяты из
[ГОСТ 25346–2013, табл.1](https://files.stroyinf.ru/Data2/1/4293773/4293773435.pdf#page=16).
Поля H/h показывают ширину допусков и предельный зазор; приложение не назначает
ими посадку подшипника. Степень точности венца по Т7 — отдельный параметр.
