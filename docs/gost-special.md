# Уточнение контакта и изгиба зубьев

## Приложение 7. Допускаемое напряжение по двум зонам

В зоне I работает головка шестерни с ножкой колеса. В зоне II работают головка колеса и ножка шестерни. Для каждой зоны программа выбирает меньшее из двух допускаемых напряжений с поправкой μK на работу головки. Затем ограничивает отношение зонных значений по скорости и твёрдостям. Формула (46) объединяет зоны с весами εα1δI и εα2δII. В веса входит торцовый угол зацепления αtw собранной передачи. [Скан ГОСТ 21354–87, таблица 28 и чертёж 28](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=89)

Функция `gost_special.helical_allowable` принимает σHP1 и σHP2 из формулы (36), диаметры вершин и основных окружностей в мм, числа зубьев, αtw в градусах, окружную скорость в м/с и твёрдости поверхностей. Для μK нужны значения HB, для сравнения с 350 HV нужны значения HV. При смешанной паре по разные стороны 350 HV и разных допускаемых зоны расчёт вернёт причину остановки. Для равных зонных допускаемых ограничение отношения не требуется.

В результате доступны σHP в МПа (`HP`), частные перекрытия, δI, δII, исходные и ограниченные допускаемые напряжения. Контрольный пример чертежа 28 при z₁ = 30, z₂ = 45, αtw = 22,1°, εα1 = 0,96 и εα2 = 0,57 даёт δI ≈ 1,03 и δII ≈ 0,93.

## Приложение 9. Две фазы нагружения при изгибе

Для прямозубой пары с точностью по плавности до 8-й включительно таблица 13, п. 5 предусматривает уточнение, если исходное условие σF ≤ σFP не выполнено. Функция `gost_special.spur_bending` сравнивает напряжение при двухпарном контакте в вершине зуба и при полной нагрузке в верхней граничной точке однопарного зацепления. Для шестерни и колеса проверка выполняется отдельно с перестановкой индексов. [Таблица 13](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=32) · [Таблицы 33 и 34](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=100)

Требуются FtF в Н, рабочая ширина и модуль в мм, fpb1 и fpb2 в мкм, коэффициенты KA, KHv, KHβ, KFv, KFβ, степень точности и геометрия действительной пары. По высотам контактных точек вычисляются податливости четырёх зубьев и жёсткости c′a и c′v. Таблица 33 также допускает первое приближение для KFαa. Для него служит `approximation=True`. Профиль `standard` соответствует ГОСТ 13755–81, а `modified` означает модификацию ножек при c* = 0,4, Pr0 = 0,05m и ha* = 1. В полиноме для этого профиля коэффициент +3,646 умножается на xξ² согласно записи на стр. 102. В формуле для hmu сопряжённого зуба на стр. 101 напечатан диаметр впадин df.

Поля `tip` и `single` содержат напряжения в МПа для обеих фаз, поле `governing` указывает определяющую фазу. В `sigmaF` возвращается по одному определяющему напряжению для каждого венца. При расчёте с другой нагрузкой следует заново передать соответствующие силы и коэффициенты.
