# Трассировка формул проверочного расчёта

Источник: [ГОСТ21354-87, скан](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf). Нумерация ниже — приложение1 и печатные страницы. Код: `src/rating.py`. Проектировочный семинарский метод хранится отдельно в `src/engine.py` и не подменяет эти зависимости.

## Контакт

П.3.1, с.14, формулы31–33:

```
σH = ZE ZH Zε sqrt(FtH KH (u+1)/(bw d1 u))
KH = KA KHv KHβ KHα
```

Табл.6, с.15:

```
ZE = 190 для стальной пары при E=2.1e5 МПа
ZH = sqrt(2 cos βb / tan αtw) / cos αt
tan βb = tan β cos αt
Zε = sqrt((4−εα)(1−εβ)/3 + εβ/εα), εβ<1
Zε = sqrt(1/εα), εβ≥1
```

Для реализованногоx=0 имеемαtw=αt. ZE берётся как округлённое значение190 прямо из таблицы; не смешивается с точным пересчётом черезE иν.

Табл.6 п.6, с.16; табл.7–9, с.22:

```
KHv = 1 + wHv bw/(FtH KA)
wHv = δH g0 v sqrt(aw/u), не выше предела табл.7
```

При хотя бы одном колесеH≤350HV: δH=.02 для косых зубьев, .06 для прямых без модификации головки. При обоихH>350HV значения.04/.14. Приложение использует мягкий профильУ; высокотвёрдая ветвь не означает поддержку всего материального расчёта.

Табл.6 п.8, с.18–19:

```
1/c′ = .05139+.1425/zv1+.1860/zv2 при x1=x2=0
cγ = c′(.75 εα+.25)
fpbe = hypot(fpb1,fpb2)
A = .4 cγ bw (aα fpbe−yα)/(FtH KA KHv KHβ)
KHα = εγ/2 · (.9+A), εγ<2
KHα = .9+sqrt(2(εγ−1)/εγ) A, εγ≥2
1≤KHα≤εγ/(εα Zε²)
```

aα=1,yα=0 по умолчанию — осознанные проектные допущения. Полная формулаKHβ включаетfkE,Fβ,aβ,приработку и жёсткость; модуль не выдумывает отсутствующие значения.

Табл.11 п.3, с.24:

```
ZN = min((NHlim/NHE)^(1/6), 2.6) при NHE≤NHlim для однородного материала
ZN = max((NHlim/NHE)^(1/20), .75) при NHE>NHlim
NHlim = min(30 HB^2.4,120e6) в общей формуле стандарта
```

В семинарском профилеNHlim введён готовым значениемТ1. РежимII задаётNHE=NK·μH; произвольная циклограмма не анализируется. Не следует заявлять, что эти входныеТ1/μH вычислены самим ГОСТ-модулем.

Формула36, с.14; табл.11, с.25:

```
σHPi = σHlim_i ZNi ZR Zv ZL ZXi / SH
Zv = .85 v^.1 при H≤350HV; .925 v^.05 при H>350HV
ZL = 1
ZX = 1 при d<700; sqrt(1.07−1e−4 d) иначе
```

Для косых/шевронных колёс условное допускаемое пары равно.45(σHP1+σHP2), ограниченное снизуmin и сверху1.25min; для прямых используетсяmin. Это основная зависимость на с.19, не уточнённое приложение7.

## Изгиб

П.4.1, с.29, формулы37–39:

```
σFi = FtF KF YFSi Yβ Yε/(bw mn)
KF = KA KFv KFβ KFα
σFPi = σFlimb_i YNi Yδ YR YXi / SF
```

Табл.13 п.3, с.30:

```
KFv = 1+wFv bw/(FtF KA)
wFv = δF g0 v sqrt(aw/u), не выше табл.7
δF = .06 для косых/шевронных, .16 для прямых без модификации
```

Табл.13 п.4–8, с.31–32:

```
KFβ = (KHβ0)^NF
NF = (b/h)^2 / ((b/h)^2+b/h+1)
h = 2m для косых; 2m/εα для прямых
YFS = 3.47+13.2/zv при x=0, стандартная рейка без протуберанца
Yβ = max(.7,1−εβ β°/120)
Yε = .2+.8/εα при εβ<1; 1/εα при εβ≥1 для косых
```

KFβ вычисляется по этой формуле только при явно известномKHβ0; иначе он остаётся входным фактором проекта. Для прямых зубьев предварительный расчёт одной пары используетKFα=Yε=1. Для косыхKFα определяется аналогичноKHα приyα=0,aα≥.4, с границами1…εγ.

Табл.13 п.9–14, с.32–37:

```
YN = clamp((4e6/NFE)^(1/qF),1,4) для qF=6
YN = clamp((4e6/NFE)^(1/qF),1,2.5) для qF=9
σFlimb = σFlimb0 · YT YZ Yg Yd YA
Yδ = 1.082−.172 log10(m)
YX = 1.05−.000125d
```

Материальный профильУ используетqF=6. YZ=.9 для проката,1 для поковки, .8 для литья. Предварительный выбор заготовки учитываетda, а не только делительныйd; припуски назначаются при конструировании. В профилеYT=Yg=Yd=1 при заявленных технологических условиях. YR берётся из явного ввода; значение1 соответствует обычной обработке переходной поверхности приRz≤40мкм. YA=1 в исходном нереверсивном задании.

## Максимум нагрузки

П.3.2, с.28–29:

```
σHmax = σH sqrt(Tmax KHmax/(TH KH))
σHPmax = 2.8 σT для нормализованной/улучшенной стали
```

KHmax пересчитывается приTmax, без повторного умножения наKA. Коэффициент по ширине остаётся явно заданным; это ограничение модели.

П.4.2, с.52–54:

```
σFmax = σF KAS/KA                   (допускаемое упрощение п.4.2.2)
σFPmax = σFSt/SFSt · YRSt YX · YδSt/YδStT
σFSt ≈ σFlimb · YNmax · KSt        (материалы, отсутствующие в табл.19)
YNmax=4, KSt=1.3 для qF=6
SFSt=YZ Sγ
```

Для используемого приближенияYRSt=YδSt/YδStT=1. ЗначениеSγ=1.75 прямо приведено для условий материаловтабл.19; его перенос наУ является **проектным допущением**, а не подтверждённой нормой для34ХН3МА. Код отмечает необходимость назначения этого значения. Пиковый расчёт предполагает меньше10³ повторений максимума; неизвестное число пусков не превращается автоматически в «пройдено».

| Параметр | Семинар | Проверочные формулы ГОСТ |

| KHv/KFv | В знаменателе дополнительноKβ | В основных зависимостях нетKβ в знаменателе |

## Проверки реализации

`tests/test_rating.py`: 14 тестов. Проверяются граница ресурса, нижний предел ZN, разные предельные YN, неизвестное число пусков, граница 999/1000 повторений, специальный прямозубый случай, увеличение напряжений при росте нагрузки, равенство модели двух половин шеврона и одиночного венца при одинаковой нагрузке на ширину, неподдерживаемая геометрия, согласованность размеров/углов/перекрытия и некорректный импорт JSON, включая bool, NaN, infinity и неверные типы.

Независимый скалярный пример: прямые зубья, m=2 мм, z=20/40, d=40/80 мм, b=20 мм, T=10 Н·м, v=1 м/с, KA=Kβ=1, погрешности шага нулевые. Получаются εα=1.6351859635714583; KHv=1.0617831044865826; KFv=1.1647549452975539; σH=419.8472003306685 МПа; σF1=60.130474050986216 МПа; σF2=55.325859901633805 МПа. Числа рассчитаны отдельно без вызова проверяемого модуля и зафиксированы в тесте.

Каждая строка трассировки содержит численную подстановку. Выводятся активная ширина и доля нагрузки венца, геометрические перекрытия, βb, приведённые числа зубьев, жёсткости, параметры распределения, ветви и ограничения KHα/KFα, эквивалентные циклы, все применённые множители допускаемых напряжений и максимальные нагрузки. Для неизвестных исходных коэффициентов отображается именно заданное значение, без имитации его вычисления.

Тесты физических зависимостей не заменяют независимое воспроизведение численного примера из приложения11; такой эталон пока не реализован.
