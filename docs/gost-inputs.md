# Как задать условия проверки

Откройте «Исходные данные» → «Проверка по ГОСТ 21354–87». Режим «Проверить по чертежу» принимает числа зубьев, нормальный модуль, активную ширину, угол наклона и смещения двух колёс. Для цилиндрической пары с ненулевой суммой смещений начальная и делительная окружности различаются. Схема опор использует начальные окружности. [Геометрия и инструмент](gost-geometry.md)

[Открыть пример из приложения 11](https://5k4umku.github.io/drivelab/?example=gost-annex-11) · [Сопоставление с печатным расчётом](gost-example.md)

## Нагрузка

В форме циклограммы одна строка соответствует одному уровню нагрузки. Например, `1 60`, `0,7 30` и `−0,4 10` задают два уровня прямого хода и 10 % обратного хода. Для методов эквивалентных циклов и напряжений третье число задаёт частоту в долях номинальной. В JSON времени соответствует доля от 0 до 1. На остановку с нулевым моментом можно отвести часть времени.

| Метод | Что происходит |
|---|---|
| Эквивалентные циклы | Уровни сравниваются по повреждаемости. Более редкие нагрузки выше расчётной проверяются отдельно. |
| Эквивалентные моменты | При постоянной частоте вычисляются контактный момент по приближённой формуле п. 2.1 и изгибный момент для каждого показателя qF. При реверсе определяются циклы, YN и отношение TF/YN каждой стороны. |
| Эквивалентные напряжения | Сначала пересчитываются напряжения на каждой ступени при её частоте. В расчёт усталости входят уровни, прошедшие пороги приложения 3. Проверка максимума сохраняет пики. |
| Типовой режим | Табл. 35 задаёт доли эквивалентных циклов. Опция табл. 36 использует эквивалентные моменты при полном числе циклов. |

## Паспорта

В поле «Паспорта шестерни и колеса» вводятся две записи. Номер строки задаётся парой «таблица.строка», например `16.1`. Для каждой нужны название, источник измерений, способ получения заготовки, обработка корня и фактические механические характеристики. Пример заполнения есть в форме. Для поверхностного упрочнения см. два разных паспорта в [исходных данных примера ГОСТ](../examples/gost-annex-11.json). [Материальные характеристики](gost-materials.md)

## Дополнительные условия

Поля в этом разделе входят в объект `input.gost`. Вставьте одну нужную группу из списка в форме и замените демонстрационные значения на данные своего узла. При вводе нескольких групп объедините их в одном объекте JSON.

| Поле | Что задавать |
|---|---|
| `peakLoad` | Вид машины `machine` из табл. 24, например `fan` или `inductionStart`. Без `value` выбирается верхняя граница диапазона. Для плавного пуска `softStartReduction` равно 0,20…0,30. Для предохранительной муфты `clutchLimit` задаёт отношение предельного момента к номинальному. |
| `face27` | `span` — пролёт опор шестерни, мм. `distance` — расстояние до середины венца от опоры со стороны подвода, мм. `bearing` принимает `plain`, `roller`, `ball`. Стороны приложения моментов `torques` — `same` либо `opposite`. `scheme` принимает 0 для одиночной передачи или 1–5 по черт. 16. `hv` — твёрдость менее твёрдого венца. `contactGrade` — степень по нормам контакта. Формулы табл. 27 выбирают более нагруженный торец. |
| `dynamics` | Допускается `resonanceRpm` в мин⁻¹ либо `inertia1`, `inertia2` в кг·мм². Для области резонанса укажите `pitchError` и `profileError` в мкм. Добавочные массы и коэффициенты описаны в [расчёте динамики](gost-dynamics.md). |
| `refineContact`, `refineBending` | Переключатели в форме. Для контакта косых зубьев нужны HB и HV каждого колеса. При прямых зубьях приложение 9 сравнивает две фазы изгиба. [Уточнения](gost-special.md) |
| `subsurface` | Два объекта по порядку венцов или null у неприменимого венца. Для цементации указывают `core_hv`, `thickness` в мм и `steel_group`, для азотирования — глубину слоя и эквивалентные циклы. Правила для измеренной глубины и номограммы — в [приложении 8](gost-subsurface.md). |
| `design` | Пустой объект включает четыре оценки предварительных размеров. Для выбора по черт. 13 укажите схему и относительную ширину. [Раздел 5](gost-design.md) |
| `criteria` | `lifeLimitHours` задаёт верхнюю границу поиска ресурса до 10⁷ ч при неизменной односторонней нагрузке. `trials` принимает записи по H, F, HSt, FSt с числом независимых успешных испытаний `passed`, размером серии `total`, требуемой вероятностью `minimum`, односторонним доверительным уровнем `confidence` и ссылкой на протокол `source`. События в протоколе должны относиться к заданному ресурсу и максимуму нагрузки. |
| `conditions` | Фактическая температура воздуха `ambientC` в °C, признаки закрытого корпуса `closed`, стандартной рейки `standardRack` и специальных отраслевых правил `specialRules`. При отсутствии группы действует заявленная область метода. |
| `basic` | Для металлической пары по чертежу и независимо обоснованных данных используются основные формулы (1)–(30). Поля и воспроизводимый пример приведены в [тесте общих зависимостей](../tests/test_gost_criteria.py). Вводятся E в МПа, ν, коэффициенты номинальной и пиковой нагрузки, пределы каждого материала и минимальные коэффициенты запаса. |

В таблицах сравнения `—` означает отсутствие вычисленного значения. Причину можно найти в «Проверках». Журнал и документ Word сохраняют единицы, численные подстановки и выбранные ветви расчёта.
