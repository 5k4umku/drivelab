# Паспорта шестерни и колеса

В режиме проверки по чертежу откройте «Паспорта материалов». В массиве `gost.materials` первый объект относится к шестерне, второй к колесу. Строки и твёрдости выбираются независимо. Для варианта семинара с улучшением обоих венцов можно сохранить прежний способ выбора через таблицу Т1.

| Поле паспорта | Что указать |
|---|---|
| `row`, `label`, `evidence` | Номер таблицы и строки, обозначение материала и документ о его химсоставе и технологии обработки. Например, `"row":"15.1"` допускается для хромомарганцевой стали с молибденом при закалке с нитроцементационного нагрева. |
| `hb`, `hv`, `hrc` | Средняя твёрдость рабочей поверхности в каждой применяемой шкале. HB нужен для NHlim, HV для выбора ветви динамики и Zv, HRCэ для закалённых и цементированных поверхностей. Для пересчёта см. чертёж 8. |
| `rootHrc`, `coreHrc`, `rootHB` | Твёрдость переходной поверхности после ТВЧ, сердцевины у основания и незакалённой части зуба соответственно. Для строки 17.7 нужен `rootHB`. |
| `blank`, `grinding`, `rootTreatment` | Заготовка `forged`, `stamped`, `rolled` или `cast`. Шлифование корня `none`, `rough` или `finish`. Упрочнение корня `none` либо `peened` для наклёпа дробью или роликами. |
| `goodGrinding`, `YD` | При шлифовании укажите, гарантировано ли отсутствие дефектов, перечисленных в примечаниях к выбранной таблице. При наклёпе укажите Yd в пределах строки для выбранного состояния поверхности. |
| `SH`, `SF`, `severeConsequences` | Индивидуальные коэффициенты запаса. По умолчанию SH берётся по таблице 11, SF — по строке таблиц 14–17 для вероятности 0,99. При тяжёлых последствиях отказа отметка `true` повышает минимум SH до 1,25 или 1,35. |
| `flankRa`, `YR` | Ra рабочей поверхности в мкм, YR переходной поверхности. При заданных Ra обоих членов ZR определяется для более грубой поверхности по табл. 11.4. Для полирования до химико-термической обработки отметьте `polishedBeforeTreatment`. Явный YR требует собственного основания в поле `evidence`. |

## Ветви технологической обработки

| Строки | Какие дополнительные данные нужны |
|---|---|
| 14.1–14.5, цементация | Поверхность по табл. 12 выше 56 HRCэ, твёрдость сердцевины, подтверждение плавного спектра `smoothSpectrum`, концентрация углерода `carbon` в процентах для строк 1–3. Для особого случая строки 14.2 допускается `highTemperProtected=true`, когда выполнены условия примечания ** на с. 44. |
| 15.1–15.2, нитроцементация | 57–63 HRCэ, `coreHrc`, концентрации `carbon` и `nitrogen` в процентах, `smoothSpectrum`, отсутствие тёмной составляющей `darkPhaseAbsent`. Для m > 8 мм отдельно указывают наличие испытаний `specialTests`. |
| 16.1, нормализация или улучшение | Совместная область таблиц 12 и 16 составляет 180 ≤ HB < 350. Для максимального контакта нужен предел текучести `yieldStrength` в МПа. При 200–350 HB предел при максимальном изгибе берётся из табл. 19. |
| 16.2–16.4, объёмная закалка | Для совместного расчёта 45–50 HRCэ. Для зависимости 2,8σт укажите `yieldStrength` и подтвердите низкий отпуск `lowTempering`. |
| 16.5–16.6, азотирование | В совместной области таблиц 12 и 16 допустимы 700–750 HV для стали с Al или 550–750 HV для другой легированной стали. Нужны `coreHrc`, `flankRa` ≤ 1,25 мкм и `contactPatternGrade` ≤ 6 по пятну контакта. |
| 17.1–17.7, закалка ТВЧ | Табл. 12 проверяет рабочую поверхность (38–50 HRCэ), табл. 17 отдельно проверяет переходную поверхность и сердцевину. Для сквозной закалки укажите низкий отпуск и предел текучести. |

Для упрочнённой поверхности `technologyCompliant` фиксирует соответствие примечаниям о толщине, структуре и технологии в выбранной строке. Измеренные `caseDepth` (мм), `grainSize` (балл), `noFerrite` и `nitridesAbsent` позволяют проверить часть условий численно. `caseDepth` задаётся в сечении, указанном в примечании к таблице. Несоответствие даёт предусмотренное снижение базового предела изгиба через YT. Ветви электрохимической обработки корня требуют отдельного определения Yd.

Для максимального изгиба отдельно проверяется область табл. 19. Когда техпроцесс допускает несколько строк, укажите `peakRow` с основанием выбора. При цементации варианты `reheatNickel` и `directOther` различают способ закалки и группу стали. Для отдельных ветвей ТВЧ и объёмной закалки применяются `nickel` и `other`. Для металла вне таблицы 19 её приближение требует `table19Inapplicable=true`, назначенного `gost.peakProbabilityFactor`, подтверждения этого коэффициента и известного qF. Испытанный предел `testedPeakContact` можно ввести с указанием источника при отсутствии формулы максимального контакта для выбранной обработки.

Таблица 13.9 задаёт qF для однородной структуры, ряда закалённых зубьев, цементированных и азотированных поверхностей. Для нешлифованной контурной ТВЧ в короткоресурсной ветви потребуется `qF` по испытаниям. При постоянной нагрузке и ресурсе от 4 млн циклов YN = 1 независимо от показателя. При ручном переменном режиме укажите `muF` для соответствующего qF. Для азотирования, цементации и нитроцементации в общем заключении дополнительно учитывается приложение 8.

См. [расчёт смешанной пары по приложению 11](gost-example.md) и [таблицы 11–19 ГОСТ 21354–87](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=24).
