# Динамическая нагрузка в зацеплении

Приложение 5 делит рабочие частоты на четыре области по отношению n₁/nE1. До 0,85 действуют зависимости для удельных динамических сил из таблиц 6 и 13. На границах 0,85 и 1,15 включительно используется резонансная формула. Между 1,15 и 1,5 коэффициент интерполируется. Начиная с 1,5 применяется закритическая формула. [ГОСТ 21354–87, приложение 5, таблицы 25–26](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=71)

По умолчанию расчёт оценивает частоту главного резонанса по геометрии. Её можно задать из динамической модели привода или определить для колёс с жёсткими венцами и дисками по обоим моментам инерции. При расчёте в килограммах удельная жёсткость переводится из Н/(мм·мкм) в Н/(мм·м). Моменты задаются в **кг·мм²**. Если исходный момент выражен в кг·м², умножьте его на 10⁶.

Поля объекта `gost.dynamics` читаются из исходных данных проекта.

| Поле | Значение |
|---|---|
| `resonanceRpm` | Частота главного резонанса шестерни, об/мин. Можно задать вместо моментов инерции |
| `inertia1`, `inertia2` | Полярные моменты шестерни и колеса, кг·мм². Задают вместе |
| `attachedRatio` | Отношение момента жёстко присоединённой детали к моменту шестерни. При отдельном вводе этой детали в `inertia1` укажите момент одной шестерни |
| `pitchError`, `profileError` | Фактические погрешности основного шага и профиля или их допускаемые значения, мкм. Нужны с начала резонансной области |
| `coefficients`, `coefficientSource` | Внешние значения Cv и их источник для εɣ > 2 |

Величину приработки задаёт поле `gost.yAlpha` в мкм. Для прямых зубьев признак `gost.tipRelief` выбирает коэффициенты модифицированной головки при определении дорезонансных сил. При наличии массивной детали на валу шестерни добавка к удельной силе учитывается перед ограничением по таблице 7. Для пикового момента вычисление повторяется с фактической пиковой силой и KA = 1.

В столбце для εɣ > 2 на с. 73 доступного издания напечатано значение Cv1. Ячейки Cv2, Cv4, Cv5 и Cv6 пусты. В резонансной области нужны Cv2 и Cv4, в закритической — Cv5 и Cv6, в промежуточной — все четыре. При вводе внешних значений отчёт включает отдельную проверку их источника. [Таблица 26, с. 73](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf#page=74)
