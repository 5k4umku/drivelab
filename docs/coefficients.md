# Автоматический выбор коэффициентов

В исходных данных ступени можно выбрать режим 0–V, направление нагрузки,
точность и способ расчёта коэффициентов по ширине. Все вычисления выполняет
Python. Браузер и отчёт Word показывают тот же журнал с источниками.

| Коэффициенты | Откуда берутся | Условия |
| --- | --- | --- |
| μH, μF | ГОСТ 21354–87, табл.35 | Режимы I–V; для постоянной нагрузки 0 равны 1 |
| YA | Табл.13, пп.10.6–10.6.3 | Для У: 1 без реверса, 0,65 при равных моментах и циклах на двух сторонах |
| KA | Приложение4, табл.21–23 | По режимам двигателя и рабочей машины, вне резонанса |
| KHβ≈KFβ | Т5 семинара | По расположению опор и ψbd; линейная интерполяция, без экстраполяции |
| KHβ, KFβ | Табл.6.7–6.7.2, 13.4 | По заданному полному перекосу fkβ⁰, HV, геометрии и нагрузке; прямые/косые зубья, b/d₁≤1,3 |
| δH, δF, fpb | Т6–Т7 семинара | Тип зубьев, точность 6–9, модуль и фактический диаметр |
| g₀, KHv, KFv | Табл.7–9, 6.6, 13.3 ГОСТ | В проверочном расчёте — по фактическому модулю, скорости и точности |
| KHα, KFα, Zε, ZH, Yβ, Yε, YFS, ZN, YN | Формулы ГОСТ в журнале | В пределах реализованного профиля внешнего зацепления У / У |
| YR, ZR | Т4 семинара | Явно назначаемые требования к шероховатости для улучшенной стали |

Т5 — приближение семинара, а не таблица ГОСТ. Смена осевого положения венца
или опоры заново определяет столбец Т5 и запускает пересчёт размеров. При
пропуске в таблице расчёт останавливается с объяснением. Для формулы ГОСТ
fkβ⁰ включает деформации и ошибки изготовления: один допуск Fβ не заменяет
полное отклонение. HB не подставляется вместо HV.

Реверсивный режим сейчас означает равные моменты, частоты и числа циклов
обеих сторон зуба. Ресурс задаётся для каждой стороны. При неравных условиях
нужно считать стороны отдельно; ручной YA сохраняется как явный вход.
В таблице KA ячейки «2,00 и выше» и «2,25 и выше» являются нижними границами.
Это справочные оценки, а не автоматически подтверждённая динамика привода.

В скане табл.35 для III/qF=9 напечатано 0,063, в Т2 семинара — 0,036.
Профиль улучшенной стали использует qF=6 (0,065), поэтому расхождение не
влияет на него. Проверка по ГОСТ для qF=9 здесь не включена.

Материал можно задать по Т1 или своими характеристиками. В табличном режиме
шестерня сохраняет выбранный класс, колесо получает класс на две строки
мягче. Марки сталей редактируются независимо. В пользовательском режиме
сохраняются заданные HB, пределы усталости, базовые циклы и предел текучести;
источник свойств включается в проект. Связь произвольной стали с классом
таблицы должна быть подтверждена технологией и размером заготовки.

Источники: [скан ГОСТ 21354–87](https://files.stroyinf.ru/Data2/1/4294832/4294832225.pdf),
исходные таблицы Т1–Т7 семинара. Фотографии задания в репозиторий не включены.
