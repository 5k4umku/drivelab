# Методика расчёта DriveLab

## Два расчётных профиля

Проектировочная часть повторяет семинарскую последовательность Т1–Т9. Проверочная часть использует приложение 1 ГОСТ 21354–87 и явно переданные условия проекта. Они отличаются определением коэффициентов долговечности, динамики и распределения нагрузки. Их результаты отображаются раздельно.

## Исходный вариант

Схема 11, двигатель АИР90L4, 2,2 кВт и 1410 мин⁻¹; u=6,3, η=0,98, режим II, нереверсивная нагрузка, KA=1,25, Kп=2,3, 10 000 ч, точность 7. Оба колеса расположены консольно, выходной вал имеет шарикоподшипники.

По уточнению пользователя шестерня остаётся в исходной строке Т1, колесо получает класс на две строки мягче. Для У785 это У685, а не уменьшение твёрдости на 2 HB. Все связанные σHlim, σFlim и NHG меняются вместе с классом. Класс термообработки и сталь — разные параметры; в проекте сталь сохраняется по заданию, достижимость свойств для другой конструкции проверяется отдельно.

## Выбор размеров и зубьев

1. Вычисляются моменты, циклы и допускаемые напряжения.
2. Из принятого ψbd определяется ψba и предварительное a′.
3. Динамические коэффициенты проектировочной части рассчитываются на предварительной геометрии.
4. aw округляется вверх по R10. Коэффициент KFα ограничивается диапазоном 1…1,6 отдельным видимым шагом.
5. Из заданного списка стандартных модулей оставляются значения между mmin и mmax. Если вариантов больше четырёх, включённое правило семинара исключает крайние. Для меньшего числа кандидатов оно не удаляет все варианты.
6. Для косых зубьев вычисляется диапазон целых zΣ из βmin…βmax. Из ближайшего к заданному u разбиения выбираются взаимно простые z₁, z₂ с минимальной ошибкой. Для шеврона βmin оценивается по половине активной ширины.
7. Прямые зубья требуют β=0. При автоматическом выборе aw корректируется по mn(z₁+z₂)/2; явно заданный aw считается жёстким ограничением.
8. Вычисляются фактическое u, геометрия, частоты и силы; подбор не меняет заданную мощность.

Угловая скорость отображения равна физической скорости, умноженной на видимый масштаб времени. Колесо вращается с противоположным знаком и частотой n₁/uф. Для шеврона суммарная осевая сила равна нулю только при равной нагрузке половин.

## Табличные данные

`seminar_tables.json` содержит переписанные Т6–Т7. Интервалы модулей и диаметров сохраняются без выдуманной интерполяции. За пределами таблицы применение не подтверждается. Для окончательной проверки fpb выбирается по фактическим mn и диаметру каждого колеса. Коэффициенты по ширине требуют отдельной проверки при изменении расположения опор и ширины.

Для предварительной скорости применяется точное πd′n/60000. Напечатанная семинарская форма через 9550 содержит обычное округление 30000/π; различие не скрывается.

Yz выбирается по наружному диаметру как нижней оценке диаметра заготовки: круглый прокат до 270 мм, выше — поковка. Технологический припуск необходимо уточнить на этапе конструирования. Это не выбор вида заготовки по делительному диаметру.

## Численная проверка и статус

Статус `pass` относится к конкретному условию, `fail` означает его невыполнение, `pending` — недостающие сведения или неподтверждённую применимость. Наличие числового запаса не делает неизвестные условия выполненными.

В проверке по ГОСТ aα=1 и yα=0 используются как видимые консервативные допущения. Число пусков не выводится из ГОСТ: это исходное эксплуатационное данное. Значение 0 в форме означает, что оно ещё не задано. Полный перечень допущений входит в результат ядра.

## Трассировка

Каждый шаг содержит название, формулу, числовую подстановку, результат, единицу и источник. Браузер и Word используют один журнал `trace`. Формулы в DOCX являются объектами OMML и доступны для редактирования; они не превращаются в изображения.
